## 卖家：卖卡密的完整链路

### 1. 导入卡密

- **格式**：`CSV` 或 `TXT`，**必填列只有 `code`**（单列）。网页端也支持把 `.xlsx` 拖进来，由前端解析成文本后提交。
- **编码**：`UTF-8` 与 `UTF-8 BOM`。其他编码会被**明确拒绝**，平台不会替你猜编码。
- **单批上限**：一次最多 **10,000 条**，文件不超过 **5 MiB**；单条卡密最长 **256 字符**。
- **两步确认**：先做**预检**（只回脱敏统计，不回明文），你确认无误后再**原子写入**——不会写一半。
- **去重规则随商品类型固定**（不用你选，导入页会直接告诉你这一档是哪一种）：
  - **同一个商品内去重**：实体卡密（当面交易）、会员权益、游戏虚拟物品——重复的码会被挡下；
  - **完全不去重**：知识付费、数字资源类、动漫虚拟道具——允许同一个商品里存在重复的码（适合「同一个兑换码发给很多人」这种用法）。
  - 如果你卖的是**每条都必须唯一的注册码 / 激活码**，选**实体卡密（当面交易）**这一档，它会替你把重复的码挡在入库前。
- **入库 ≠ 可售**：卡密入库后，商品仍需**审核并发布**才对买家可见。

网页端在「商品管理 → 卡密导入」；App 内同样可导入（走系统文件选择器选文件，或直接粘贴文本）。

### 2. 上架与库存

- 库存有两个口径，**互不混用**：商品上架的**可售数量**，与卡密的**逐条状态**（在库 / 锁定 / 已售 …）。
- 库存构成页是**只读回显**；要补货去卡密导入页，走「修改稿」流程。

### 3. 自动发货

付款成功那一刻，系统自动完成交付：

```
买家支付成功
 └─ 系统自动把卡密交付到该订单（订单页即时展示）
     ├─ 交付后 1 分钟：订单自动置「已完成」（买卖双方都不需要点按钮）
     └─ 交付后 48 小时内：买家可发起售后
```

**交付即完成**是虚拟商品的规则：卡密一旦交付，交易即视为完成；这 48 小时是**售后期**，不是「确认收货期」。货款与「确认收货」无关——按下方结算规则进入你的结算账户。

### 3b. 实物商品的当面交易

实物商品只能**当面交易**（不邮寄）。流程同样不需要你手动点「发货」：

```
买家支付成功
 └─ 订单自动进入「待当面交易」（系统自动发货，你无需操作）
     ├─ 你与买家当面交付；买家当场点「确认收货」（一手钱交一手货）
     ├─ 或者由你（卖家）在卖家中心 / App 的订单里点「确认完成当面交易」
     ├─ 买家 2 天内没点、你也没点：系统默认收货，订单自动置「已完成」
     └─ 交付事实成立后 48 小时内：买家可发起售后
```

**面交单的「确认收货」决定了钱什么时候进你的「可结算余额」**：交付事实成立（买家确认 / 你确认 / 2 天默认）后才能进。所以当面交货时提醒买家**当场点一下确认收货**；即使买家忘了，2 天后系统也会默认收货，不会一直卡住。

## 资金与结算

- **清算由持牌第三方支付机构完成**，平台**不接触交易资金**、也不是支付机构。
  **资金不走平台账户**：买家付款成功即按约定分账，卖家份额落在你**自己在持牌机构开立的结算账户**上——是**分账直达**，不是「先收进平台、再由平台转付」的中间账户模式。
- **结算台账四个分区**（**App 与卖家中心的文案逐字一致**）：**可结算余额 / 交易中金额 / 已结算金额 / 售后冻结金额**。款项进「售后冻结金额」的条件是**售后已被平台受理仲裁**（`freezeState=CONFIRMED`）；只是发起、还没受理的售后，对应款项仍在「交易中金额」里。
- **入账时点按渠道**：「可结算余额」的入账时点与「自动结算到绑卡」的**周期是两件事**。共同前提是**交付完成**（虚拟卡密单付款后即完成；实物面交单要等交付事实成立：买家确认收货 / 你确认完成当面交易 / 2 天默认收货），再按渠道叠加：**微信小程序收款单**另需微信结算到位（有最晚入账时间）；**买家站网页的微信收款与支付宝收款**没有额外的渠道结算前置，交付完成后即进入。
- **出金**：按结算配置**自动结算到你绑定的结算卡**——**没有需要你发起的「提现」操作**，也不需要你点任何按钮，**到账 0 手续费**。（卖家中心若出现「自动提现到账」字样，指的是持牌机构侧自动出款，不是你发起的动作。）
- **费率**：**平台服务费 2%**（卖家结算 98%），**单档、不分档**；手续费最低 0.01 元。如有账户级单独约定，以结算页实时展示为准。
  费用在订单创建时按当时的配置**快照**计算，逐单都能在订单里看到——历史订单不会被后来的调整改动。
- 费率如有调整，平台会**同步更新卖家中心与本说明**；对账与报价一律以生效配置与逐单快照为准。

> 结算周期、入账时点、费率与到账时效都会随配置与渠道变化：**一律以卖家中心展示的生效配置为准**，不要把它抄进你的对外文案。

## 售后与争议

**两级通道，平台只在一处介入：**

1. **买卖家协商**：买家发起售后后，双方可在订单内协商，卖家可给出退款方案，也可以双方一致关闭。
2. **平台仲裁**：协商不成可申请平台介入。**售后单发起满 72 小时后可申请**；卖家在售后链内**明确拒绝**的可以提前申请。**每张售后单只受理一次仲裁**。

其他你会用到的规则：

| 规则 | 说明 |
| --- | --- |
| 售后期 | **交付事实成立后 48 小时内**可发起售后，窗口外不再受理。**虚拟卡密与实物面交同档**（虚拟卡密从交付完成起算，实物面交从买家确认收货 / 你确认完成当面交易 / 2 天默认收货起算） |
| 卖家响应时限 | 有明确的响应时限与提醒；**超时不会由平台自动立案**，而是给买家**提前申请平台仲裁**的通道（本来要等满 72 小时冷却） |

| 退款执行 | 仅在平台决策链内执行，没有「卖家一键退款」入口 |

## 经营规则与信用

卖家信用按售后责任**累计计分**，分数越高代表经营风险越高；达到不同阈值会分别触发：

1. **搜索降权**（店铺与商品在小豆集市搜索结果中靠后，店铺直达不受影响）
2. **暂停发布新商品**（在售商品保留）
3. **冻结经营**（与账号经营状态一致，解除需平台最高权限审批）

诚实经营、按约定交付，分数自然保持健康；被判买家恶意的售后会**返还分数**。

## 常见问题

**开店要花钱吗？要什么资料？**
注册免费。个人主体用身份证即可进件；个体工商户与企业另需营业执照。资料按进件向导逐项提交，审核通过即可开业。

**没有营业执照能开店吗？**
可以。主体类型支持**个人**。

**卡密怎么导入？支持 Excel 吗？**
支持 `CSV` / `TXT`（必填列 `code`），网页端也支持把 `.xlsx` 拖进去。一次最多 10,000 条、不超过 5 MiB，先预检再确认入库。**注意**：入库后商品仍需审核并发布才对买家可见。

**要我自己发货吗？**
不用。卡密商品是**自动发货**：买家付款成功即交付。

**平台收多少手续费？**
平台服务费 **2%**（你结算 **98%**），**单档、不分档**；手续费最低 0.01 元。费用在订单创建时按当时的配置快照计算，订单里逐笔可见。

**钱什么时候到我账上？要提现吗？**
买家付款后资金由持牌机构按约定分账；你的份额按结算配置**自动结算到已绑定的结算卡**——**次日自动到账**，**没有手动提现这一步**，**到账 0 手续费**。具体周期与入账时点**以卖家中心「结算」里展示的生效配置为准**。

**支持微信和支付宝收款吗？**
都支持。买家在下单页可以用**支付宝**或**微信**付款，全程免注册。下单页实际展示哪种支付方式，以下单页为准。

**平台会不会碰我的钱？资金安全吗？**
不会。平台**不是支付机构**，也**不接触交易资金**：买家付款成功后，资金在**持牌第三方支付机构**侧按约定分账，卖家份额进入你**自己在机构开立的结算账户**，再按结算配置自动结算到你的结算卡。平台不经手你的银行账户信息，也没有「先收进平台、再由平台转付」的中间账户——这也是我们和「免签 / 第四方代收」那类做法最根本的区别。

**买家怎么找到我的店？**
把店铺链接发给买家即可；平台内的商品也会出现在小豆集市搜索与店铺页。

**买家买到假卡/不能用怎么办？**
买家可在 App 内发起售后，走「买卖家协商 → 平台仲裁」两级通道。网页端为免注册游客单，平台不参与其售后，订单页会展示你的联系方式供买家直接沟通——**这也是要求你在店铺留真实有效联系方式的原因**。

**能卖实物吗？**
**当面交易可以，邮寄暂时不行**。同城约见交付的实物、以及实体卡密的当面交易都可以挂；需要寄快递的商品现在挂不了（平台暂缓承接邮寄订单）。面交不需要你点「发货」，付款后订单自动进入待当面交易，买家当场点「确认收货」，2 天未点系统默认收货。

**有 App 吗？**
有。网页端与 App 双端经营；买家在 App 内可使用完整的售后与争议功能。
