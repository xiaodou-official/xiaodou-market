## 卖卡密的完整流程

### 1. 把卡密导进去

- **文件**：`CSV` 或 `TXT`，**只要一列，列名 `code`**。电脑端也支持直接把 `.xlsx` 拖进去。
- **编码**：`UTF-8` 或 `UTF-8 BOM`。别的编码会**直接报错**——我们不会替你猜。
- **一次能导多少**：最多 **10,000 条**，文件不超过 **5 MiB**，单条卡密最长 **256 个字符**。
- **先看后写**：先做一次**预检**（只给你看统计数字，不显示卡密内容），你确认没问题了才真正入库——**要么全成功，要么全不动，不会写一半**。
- **重复的码怎么办**（**不用你选，导入页面会直接告诉你这一档是哪种**）：
  - **同一个商品内去重**：实体卡密（当面交易）、会员权益、游戏虚拟物品——重复的会被挡下；
  - **完全不去重**：知识付费、数字资源类、动漫虚拟道具——同一个商品里允许有重复的码。
  - 卖**每条都必须唯一**的注册码 / 激活码，就选**实体卡密（当面交易）**这一档。
- **导进去 ≠ 能卖**：商品还要**审核通过并发布**，买家才看得到。

电脑端在「商品管理 → 卡密导入」；手机上也能导（选文件，或者直接粘贴）。

### 2. 上架和库存

- 库存看两个数，**别混**：商品页上写着**能卖几件**，卡密列表里是**一条条的状态**（在库 / 锁定 / 已售…）。
- 库存明细页是**只读的**，看看就好；**要补货去卡密导入页**走「修改稿」。

### 3. 发货：全自动，你不用管

买家付钱那一刻，系统就把卡密交到他订单里了：

```
买家付钱成功
 └─ 系统自动把卡密放进这个订单（买家的订单页马上能看到）
     ├─ 1 分钟后：订单自动变成「已完成」（你和买家都不用点）
     └─ 之后的 48 小时内：买家可以发起售后
```

**卡密给了就算交易完成**：这是虚拟商品的规矩。那 48 小时是**售后期**，不是「等买家确认收货」——钱不卡在「确认收货」上，按下面的结算规则走。

### 4. 卖实物（只能当面交易，不寄快递）

实物商品只能**当面交付**。同样不用你点「发货」：

```
买家付钱成功
 └─ 订单自动进入「待当面交易」（系统自动发货，你不用操作）
     ├─ 你们见面交货，买家当场点「确认收货」（一手交钱一手交货）
     ├─ 或者由你（卖家）在卖家中心 / App 的订单里点「确认完成当面交易」
     ├─ 买家 2 天没点、你也没点：系统默认收货，订单自动变成「已完成」
     └─ 交货事实成立后 48 小时内：买家可以发起售后
```

**面交单里「确认收货」决定钱什么时候能结给你**：得等交货事实成立（买家点、你点、或 2 天默认）才行。所以当面交货时，**提醒买家当场点一下「确认收货」**；就算他忘了，2 天后系统也会默认收货，不会一直卡着。

## 钱怎么到你手上

- **央行持牌机构清算，安全可靠的个人和企业支付接口**：钱由**有支付牌照的支付公司**处理。

- **结算页上有四个数**（App 和卖家中心写的字一模一样）：

  | 那个数 | 什么意思 |
  | --- | --- |
  | **可结算余额** | 现在能结给你的钱 |
  | **交易中金额** | 还没到点、暂时不能结的（比如货还没交完） |

## 出了问题怎么办

**两步走，我们只在第二步出手：**

1. **你们自己商量**：买家发起售后后，你可以在订单里跟他谈，给他一个退款方案，也可以双方都说好了直接关掉。
2. **申请平台介入**：谈不拢就申请我们介入。**售后发起满 72 小时后可以申请**；你在售后里**明确拒绝过**的，买家可以提前申请。**每一张售后单只受理一次介入**。

其他你可能用到的：

| 规则 | 说明 |
| --- | --- |
| 售后期 | **交货事实成立后 48 小时内**可以发起售后，过了就不再受理。**卡密和实物面交是同一个时限**（卡密从交付完成算，面交从确认收货 / 你确认 / 2 天默认收货算） |

| 证据 | 商量和介入过程中提交的凭证，我们按规则保存，用来判断 |
| 退款 | 只在平台的决策流程里执行，**没有「卖家一键退款」的按钮** |

## 关于信用分

售后里被判有责任会**累计扣分**，分越高说明风险越高。到不同档位会分别触发：

1. **搜索靠后**（你的店和商品在小豆集市搜索结果里排后面；直接把店铺链接发出去不受影响）
2. **不能再发新商品**（已经在卖的不动）
3. **冻结经营**（跟账号的经营状态一致，要解冻得平台最高权限批）

老老实实做生意、按约定交货，分自然就好；**被判买家恶意的售后，分会还给你**。

## 常见问题

**开店要花钱吗？要什么资料？**
注册免费。个人用身份证就行；个体户和企业再加营业执照。跟着向导一项项交，审核过了就能开业。

**没有营业执照能开店吗？**
能。有**个人**这个主体类型。

**卡密怎么导？Excel 行吗？**
`CSV` / `TXT` 都行（只要一列 `code`），电脑端也能把 `.xlsx` 拖进去。一次最多 10,000 条、不超过 5 MiB，先预检再确认入库。**注意**：入库之后商品还要审核并发布，买家才看得到。

**要我自己发货吗？**
不用。卡密是**自动发货**，买家一付钱就交付。

**收多少手续费？**
服务费 **1.5%**（你拿 **98.5%**），**一档，不分档**；手续费 0.01 元起。费用在下单那一刻算好，订单里一笔一笔都能看到。

**钱什么时候到我账上？要提现吗？**
买家付钱后由支付公司按约定分账；你那份**第二天自动转到你绑定的银行卡**，**没有手动提现这一步**，**转出 0 手续费**。具体时间以卖家中心「结算」页当时显示的为准。

**微信和支付宝都能收吗？**
都能。买家在下单页可以用**支付宝**或**微信**付，全程不用注册。显示哪个用哪个。

**会不会碰我的钱？安全吗？**
不会。**央行持牌机构清算，安全可靠的个人和企业支付接口**：买家付钱后，钱在**有支付牌照的支付公司**那边分好，你那份进**你在支付公司开的账户**，再自动转到你银行卡——这就是我们和「免签 / 第四方代收」那类做法最根本的区别。

**买家怎么找到我的店？**
把店铺链接发给他就行；平台里也能搜到你的商品和店铺。

**买家买到假卡 / 用不了怎么办？**
他可以在 App 里发起售后，走「先协商 → 再平台介入」两步。网页端是不用注册的游客单，我们不介入它的售后，订单页会把你的联系方式给买家，让他直接找你——**这也是为什么要求你留真实有效的联系方式**。

**能卖实物吗？**
**能当面交易，暂时不能寄快递**。同城约见交付的实物、实体卡密的当面交易都可以挂；要寄快递的现在挂不了。面交不用你点「发货」，付完钱订单自动进入待当面交易，买家当场点「确认收货」；他 2 天没点就系统默认收货。

**有 App 吗？**
有。电脑和 App 都能经营；买家在 App 里能用完整的售后和争议功能。
